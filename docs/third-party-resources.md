# Third-party resources

TripAi uses React, Vite, FastAPI, PydanticAI, LangGraph, LangSmith, PostgreSQL, Caddy
and provider SDKs. Dependencies retain their upstream licenses; Python and frontend
dependency versions are recorded in `requirements.lock` and `package-lock.json`.

Public sample photographs retain the source, author and license metadata in
`backend/samples/photo_manifest.json` and the generated frontend sample data.
The itinerary Review view exposes attribution. Provider-returned Google Maps photos
must retain their supplied author attribution. Do not redistribute photos under an
assumed project-wide license.

The multi-agent travel-planning course informed the project concept. This document
does not claim that all course material or third-party media may be relicensed.
Before publishing, confirm any copied material's terms and choose a license for
the code you own. No blanket open-source license has been assigned during this work.
